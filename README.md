Forex Signal Web Dashboard (EUR/USD)

A professional, real-time Forex Signal Web Dashboard built with Vanilla JavaScript and Twelve Data API, featuring technical indicators, market session filters, ATR volatility checks, and interactive charting.

## Features

- **Real Market Data:** Integrates with Twelve Data API for live EUR/USD time-series data across multiple timeframes (1min, 5min, 15min, 30min, 1h).
- **Advanced Technical Indicators:**
  - EMA 9 & EMA 21 (Trend Confirmation)
  - Wilder RSI (14) (Momentum & Overbought/Oversold detection)
  - MACD (Line, Signal, and Histogram)
- **Robust Signal Engine:** Generates clear **BUY**, **SELL**, or **WAIT** signals based on strict confluence logic.
- **Market Filters:** Includes Market Session tracking (London/New York sessions) and ATR Volatility filtering.
- **Interactive Candlestick Charts:** Powered by *TradingView Lightweight Charts*.
- **Signal History Log:** Keeps track of recent signals and reasons directly on the dashboard.
